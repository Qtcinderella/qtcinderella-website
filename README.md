# QTCinderella — Frontend Portfolio Concept

A responsive, frontend-only creator portfolio and booking landing page.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For a better local development experience, use VS Code with Live Server.

No backend, database, build tools, or package installation are required.

## Included
- Responsive single-page layout
- Neon / futuristic visual direction
- Animated reveal-on-scroll effects
- Mobile navigation
- Project links and social links
- Management email booking CTA (`mailto:`)
